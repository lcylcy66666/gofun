# VocabBar website

Static Traditional Chinese landing page, support page, and privacy policy for VocabBar. Serve the repository root through GitHub Pages using **Deploy from a branch**. There is no custom build workflow.

The contact email is intentionally pending. Add a working support contact before using `support.html` as the App Store support URL. Recheck the privacy policy against the shipping app before submission.

Local preview: `python3 -m http.server 8765` from this directory, then open `http://localhost:8765/`.
